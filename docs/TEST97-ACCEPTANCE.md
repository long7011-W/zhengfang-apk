# 1.0.97 测试版修复与验收

## 已实现

- 校园服务已经记住的教务登录共享授权会自动恢复，不再要求重启后点击“使用本校教务登录”。同意记录读取与内存登录会话分开：会话尚未建立或凭据失效时，先复用 App 的静默续期，恢复成功后进入页面；失败只提示登录，保留授权。页面观察登录变化及返回前台，加载在交付前标记，避免自动重放已发送的插件页面操作；撤销、换账号和换包后的校验仍执行。会话池不再复用已退休对象。
- 成绩学期仅对 `studyOptions.gradeTermFormat=academic-year-semester` 的提供者启用本地补全。八月切换学年，提供当前及前七学年的已到来常用学期；学校名称与查询 ID 优先，未来学年通常隐藏，确实返回过成绩的学期保留。补全不改变课表当前学期。用户选择、缓存和学校列表刷新错误分别保留。
- 共用选择器的绝对行号渐入改为首屏相对序号和有界延迟；动画结束后所有可用行完全可见，滚动新行不等待计时。两行名称和大字体使用实际行高。玻璃背景、形变和折射参数保持。
- 成绩页收起的选择栏恢复原先单行、常规字体下 50 dp 的紧凑高度。撤回造成左侧缩进的280dp限宽与右对齐，恢复原内容区宽度；收起、展开及再次关闭均保持原左右边界，不增加菜单宽度。窄窗口仍受可用宽度限制，菜单保留两行名称。内置学期监听日期、时间、时区变化，并在返回前台时检查日期，八月及二月自动补充到来的学期。已有有效选择不会因本地日期改变而跳转，不为补全主动刷新学校接口。
- 新正方公共协议锁定库 3.2.4 增加可选只读 `selection.filters`。网页未开放时禁用筛选；开放时结合静态选项及网页开关对应的动态来源，多选、应用、清空均使用学校查询参数。输入按账号、提供者、轮次、筛选定义与十五分钟有效期校验；普通页面令牌变化不使授权或筛选失效。旧版本库保留原样。
- 设置首页恢复“退出预览 / 退出登录”，真实退出确认一次，预览直接结束且保留真实账号与缓存；清空任务栈防止返回旧预览。账号子页不重复提供退出。
- SDK 3.2.7 / API 3，同步契约、App 资源、模板和网站文档。新声明与方法最低 code 97，旧六项选课能力组继续有效，87/96 客户端拒绝新包。现有凭证、确认及防重放边界未放宽。
