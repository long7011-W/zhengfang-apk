# App 1.0.124

## notes

- 新增青果 KINGOSOFT 教务，提供可复用的登录、课表、成绩、考试、校历与选课协议；新增湖南汽车工程职业大学学校适配，支持统一认证账号密码登录。
- 新增辽宁工程技术大学学校配置，通过学校 WebVPN 完成认证；修复该校学期、身份页、课表及分批考试的读取，校园地址可识别并保存为对应 WebVPN 入口。兼容登录完成页的会话后缀，正确更新浏览器 Cookie，并为本校连续查询保留必要间隔。
- 修复学校插件已安装并选择“使用适配”后，旧内置选择仍覆盖插件的问题。学校搜索、插件中心与开发者工具统一保存实际选择，保留原学校和账号记录；学校登录扩展与继承查询分别使用对应提供者。
- SDK、公共协议、开发模板、网站开发包与审核契约同步到 3.7.0，API 主版本保持 3；新增青果继承配置及 EAMS WebVPN 参数。
- 包含 v1.0.123 之后的更新历史整理，以及镜像校验卡住时的重试修复；学习通插件继续保持此前的独立交付范围。

## verification

湖南汽车工程职业大学使用全新 Cookie 验证生产 CAS 加密密码提交：15 个学期、18 条课表安排、55 条成绩、10 条已选。辽宁工程技术大学通过授权的 WebVPN 登录续接：62 个学期、20 条课表安排、32 条成绩、8 条考试。

两校选退课写入仅合成验证，没有真实选课或退课。湖南汽职选课窗口关闭、当前考试为空且未提供节次作息；辽宁工大无开放选课轮次，校历不支持。超出宿主周次范围的实际课程明确报错。

Android API 32 实际执行 7 项验收全部通过，涵盖学校选择、QuickJS 扩展登录、湖南汽职全新登录、辽宁工大浏览器会话续接及两校只读查询。SDK 338 项回归通过。设备验证不代表 Android WebView 完整认证交互或所有手机兼容；河北传媒使用合成 1.2.1 扩展，不声称已验证开发者原包的真实学校账号。

App 本地全量重新执行 1354 项 JVM 用例：1350 通过、4 跳过、0 失败；AndroidTest 编译通过，Lint 0 错误。
