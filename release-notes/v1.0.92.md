# v1.0.92

## notes

减少插件授权的重复点击：支持一键允许并记住，普通关闭和同账号重登可复用授权。
已审核的已读更新可与教务登录合并授权，支持刷新时更新多条状态后读取文本；未声明可信接口的旧插件仍需确认。
加强插件凭证隔离、请求范围检查和个人数据外传授权，增加授权撤销管理。
修复通知启动时把空图标当作左上角图标播放动画的问题，保留正常桌面启动动画。
调整文字入场绘制和导航动画状态，缓存成绩页面转换与统计，减少切换时的重复工作。
配套 SDK 3.2.4 新增操作范围与数据接收方声明，插件站增加自动检查报告和人工复核门槛。

### 授权与插件安全

- 分离可持久化的用户同意和当前会话句柄；同账号重登重新绑定句柄，旧句柄、撤销后的回调与待确认弹窗不能恢复授权。
- 授权框使用直接操作按钮；首次共享登录可以合并已审核的已读更新，同一原生运行实例的并发授权合并等待。服务刷新可以更新多条状态后获取文本，普通关闭保留同意。
- 增加经过验签的发行身份、精确请求范围及结构化参数检查、凭证回显防护、持久数据标签和独立外传授权；QuickJS 服务使用隔离 UID。
- 未知端点、没有可信声明的旧插件及高风险提交不会自动获得永久免确认权限。

### 启动、文字与切换

- 通知启动缺少系统图标时直接移除启动层，不再使用空 View 的零坐标和默认尺寸播放动画；真实图标在布局完成后换算位置，取消或脱离窗口时释放覆盖层。
- 导航与入场动画使用可观察状态，恢复常规透明度合成，快速切换限制残留过渡页面。
- 缓存成绩转换和学期信息，将统计移出主线程；玻璃捕获拒绝过期帧回写并记录耗时，保留实时效果。

### SDK、网站与验证边界

- SDK 3.2.4 保持 API 主版本 3，同步 host-api、App 资源、CLI 校验和开发说明。网站增加绑定源码和包摘要的审核报告、独立 runner 签名验证及人工复核。
- 本地 App 完整 JVM 760 项（756 通过、4 项可选真实账号检查跳过）；随后启动图标改动的定向回归 14/14。独立开发套件 JS/QuickJS 187/187、网站 Worker/SQL 56/56、独立 SDK 重建与消费示例通过。发布流水线会再次运行其完整检查。
- Issue #41 的实际第三方插件端点接入仍待完成。API 32 GPU、WebView、隔离 UID 和实际设备动画仍待设备验收，不宣称所有学校或设备已经验证，也不宣称卡顿已彻底消除。
