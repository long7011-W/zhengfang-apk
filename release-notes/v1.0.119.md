# 1.0.119 公告中心与插件后台运行修复

## notes

- 新增 App 公告中心，在设置中查看未读公告、搜索、分类筛选及全部标为已读。普通公告默认只显示未读标记，重要公告可弹窗提醒。
- 公告支持图文、封面及多个功能按钮，可进入课表、成绩、插件中心等页面；重要提醒每次回到前台最多展示一条，更新修订后重新提示未读。
- 插件站管理端新增公告编辑、排版工具、模板、图片上传、实时预览、按钮排序、版本与学校定向、定时发布、撤回和操作记录。保存草稿后需单独确认发布。
- 修复内置脚本浏览器在收起页面、按 Home 或切换 App 后暂停定时器与网络请求的问题；任务停止后及时结束后台执行。
- 修复临时输入的答题凭据无法用于脚本设置或提示框的问题，并保持账号与插件之间的凭据隔离。
- 修复浏览器关闭时过早结束进程导致 Cookie 未完成保存的问题，重启后保留已写入的登录状态。
- 地图服务增加高德、百度的服务端接入与多 Key 轮询、故障冷却；密钥只存云端，搜索保留城市、航站楼和楼栋信息。国内来源需由维护者配置有效 Key 后启用。
- 修复正式推广时镜像回执的工件定位。SDK 3.6.0 / API 3 保持兼容，本次为普通更新。
