# v1.0.96

## notes

修复部分机型插件服务启动超时的配置回归，恢复非导出的独立插件进程。
课表每天节数随有效教务作息自动同步，用户手动设置优先，不增加确认弹窗。
修复关闭液态玻璃后的课表顶栏遮罩路径，统一课表与成绩的普通圆角底色。
共享学校登录按准确站点一次授权，减少通知正文读取与已读更新的重复确认；教务适配卸载入口统一。
课程详情支持按周显示课程号、学分、教学班、授课内容及备注等插件返回字段。
精简设置与插件分类/详情，增加基础宽窗布局和原生插件视口能力。SDK 3.2.6 / API 3。

## changelog

### 启动与课表同步

- #50：移除 1.0.92 重新启用的 `isolatedProcess`，保留非导出的 `:academic_plugin` 独立进程，避开部分设备在服务发布前杀死隔离进程的启动路径。10 秒绑定预算、失效连接回收与交付后不重放保留。
- 插件进程恢复与主 App 同 UID，失去隔离 UID 对引擎逃逸、私有文件和系统权限的额外保护；QuickJS 资源限制及宿主凭证/请求检查仍保留，不能视为相同系统级隔离。
- #51：根据有效作息最大节次同步每天节数，现有范围 8–16，按账号保存。手动保存（含相同数值）及旧手动设置优先，不弹额外确认；空作息不重置节数。
- 节次补充失败不丢失已获取课程，刷新失败保留缓存并展示原因。本机诊断区分服务绑定、脚本和学校网络阶段。

### 插件与界面

- 非玻璃模式：课表顶栏取消独立硬件阴影并填满完整圆角区域；成绩顶栏和状态栏补齐普通底色回退，保留原有显隐与布局。玻璃开关变化同步停用采样，前景文字/按钮独立绘制，开启玻璃的光学效果参数保持不变。
- #41/#42：站点授权、当前登录会话的“仅本次”、旧插件 JSON body/已读刷新支持，合并外部操作与披露确认；凭证不可导出、撤销检查及未知结果防重发继续保留。
- #44/#45/#47/#48：账号操作集中，教务适配卸载/内置停用统一；按功能筛选插件，登录入口默认教务；详情按权限、来源、支持与历史分层。
- #46：可选课程 details 贯通协议、缓存、快照、导入和提醒序列化；当前周内容优先，纯文本显示，旧缓存兼容，展示字段不改变课程标识。
- #49：基础窗口宽度分档与内容上限，前台原生页可协商 ui.viewport@1。原生页面内存状态在配置重建期间保留；主登录保留输入但取消在途登录并提示重试。
- 方向配置在 Activity 启动时读取当前窗口资源，避免 Manifest 引用屏幕尺寸变体失效；手机保持竖屏，大屏解除方向锁定。

- OEM 启动对照来自 Issue 报告，维护者设备验收、Android 17 性能、API 32 GPU、WebView 和实际学校在线数据继续延期。
