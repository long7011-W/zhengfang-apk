# App 1.0.121

## notes

- 修复插件多页面及后台任务并发时脚本引擎崩溃、页面持续加载和“插件进程失败”的问题。引擎创建、执行和释放统一调度，等待网络时其他插件页面仍可响应。
- 合入 PR #67：在校园网 IPv6 或部分 IP 不可达时尝试可用连接，保留总超时、取消和防重复提交约束。
- 学习通 0.2.8 插件单独本地交付：增加答题密钥购买入口、Token 获取和填写说明，注明“开发者个人使用推荐 · 非赞助合作”。此前签到、定位与待核对恢复修复继续保留。

## verification

MuMu Android 12 已复现修复前的 JNI 全局引用崩溃：并发回归在 4.585 秒内失败。修复后的沙箱设备测试 13 项全部通过，包含 240 次并发调用、状态隔离、慢网络期间的其他页面响应、取消恢复、时间及内存上限、进程退出和防重放。相关 JVM 单测 49 项通过。

正式 App 120 的 19:00 临时课程在保持后台时于 18:50 收到课前通知，验证提前 10 分钟提醒。真实课程任务和最终签名测试包的验收结果单独记录；以上证据不代表 vivo 真机验收。

## distribution

新版本使用独立的 121 测试构建，不覆盖已经发布的 120 APK。正式推广仍须通过插件平台一致性检查，并使用同一份验收后的签名产物。学习通插件源码和安装包不提交、不推送、不上架。
