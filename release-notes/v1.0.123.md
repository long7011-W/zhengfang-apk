# App 1.0.123

## notes

- 新增原生插件后台作业队列支持。一次启动固定本轮作业与自动操作范围，离开插件页后继续运行，可随时从原生页面或常驻通知停止。
- 学习通 0.2.8 r8 插件单独本地交付：作业 Tab 新增独立设置，支持“自动提交”和“自动下一份”，默认关闭、按账号保存。只开启自动下一份时，保存成功后继续；开启自动提交时，平台确认已交后继续。
- 作业缺少答案、保存失败、额外提示或提交结果不明时暂停，保留结果和恢复入口；每份作业的保存、提交不会自动重复发送。新增本轮处理记录及灰色操作按钮的具体原因。
- 修复多页面存在同名按钮时后台操作可能选错页面的问题，自动操作绑定自己启动的作业及实际文档。SDK、开发包、插件站说明与公开审核自检同步到 3.6.2，新队列功能需要 App 123。

## verification

本地作业与队列合成测试 54 项通过，覆盖四种开关组合、账号隔离、存储失败、提交回执与未知结果。App 定向 JVM 测试 29 项、后台隔离与 Gecko 回归 28 项、审核规则测试 5 项、发布脚本测试 153 项通过。

CI 完整构建、最终签名包及 MuMu 验收随交付记录。正式自动提交分支使用合成测试，真实作业的正式提交由用户操作；设备验证不会把已交作业重新作答。MuMu 结果不代表所有手机的后台运行表现。

## distribution

SDK 3.6.2 / API v3，内置扩展 3.4.0.11。正式推广须通过网站、SDK、开发包和审核工具链一致性检查，沿用本轮签名构建产物并启用强制更新。学习通插件只本地交付，不提交、不推送、不上架。
