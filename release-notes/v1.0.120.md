# 1.0.120 高德地图、个人 Key、后台提醒与多套作息预设

## notes

- 合入 PR #66：支持保存多套作息时间预设、在当前学期应用和撤回；完善账号与学期隔离，修复旧作息冲突时无法应用有效预设的问题，保存或应用失败会明确提示。
- 修复统一登录经过六次跳转无法进入教务的问题，通用教务与插件宿主的连续跳转上限统一为十二次；每一跳仍检查授权来源、HTTPS 和凭据范围，禁止自动重放已提交的 POST。
- 修复后台恢复时课程提醒可能丢失的问题，覆盖提前 10 分钟的提醒；冷启动、系统恢复时重新登记已有计划，避免尚未送达的提醒被下周计划覆盖。零提前量和轻微延迟允许在上课后五分钟内送达，已过期的历史提醒不补发。
- 服务器登录过期后继续使用本地课表提醒，切换、退出或删除账号仍隔离并取消相应提醒。增加由系统调度的本地恢复任务，课程提醒和桌面小组件无需依赖页面一直打开。
- 小组件在有权限时使用准确的课程边界刷新，无精确闹钟权限时回退系统普通闹钟；不为小组件唤醒休眠设备。修复已通过 Android 自动化回归，vivo 的具体系统后台限制仍需用户设备验证。
- 签到选点接入高德原生地图，支持缩放、点选和坐标换算；系统当前位置、手动选点与输入坐标不消耗 Web 搜索额度。
- 修复国内地址解析过度截断、校区和小区名称丢失，以及“T1 航站楼”与“1号航站楼”等名称差异；保留城市、校区、航站楼、到达或出发限定，避免误选其他地点。
- 新增“设置 → 地图服务”，允许用户接入自己的高德 Web 服务 Key。网站加密提交、核实免费额度后启用，App 使用 90 天个人连接码；支持查看额度、重新连接、撤销和切换公共服务。
- 个人 Key 仅供本人连接的设备搜索，独立于主动捐赠的公共池；失效、暂停、到期或额度耗尽时明确提示，不自动使用公共 Key。
- 插件站开放 Key 捐赠渠道，支持加密提交、人工审核、用途标识、独立入口开关与自行撤回。同一高德账号的个人与捐赠 Key 共用免费额度，轮询和重提不能叠加或清零。
- 地图管理端严格限制单 Key 与账号共享总池，每月最多 5000 次且不超过核实的免费额度；请求前原子计数，失败和重试也计数，缓存命中不扣，额度耗尽或权益到期停止调用。
- 高德配置采用客户端认证、加密下发、防重放与限流；Web Key 保留在云端，个人连接码使用 Android Keystore 加密存储并排除备份，搜索签名绑定个人连接，认证头不转发给上游或重定向地址。
- 高德 SDK 经隐私同意后初始化，地图随页面暂停、恢复和释放；兼容 SDK 3.6.0 / API 3，同步地图、个人 Key、捐赠及公告使用文档。本次 1.0.120 按用户要求强制更新。
- 插件站文档增加完整网页阅读：目录、搜索、深浅色、代码复制、打印与手机布局；保留 Markdown 下载和复制给 AI 的入口，旧文档链接在浏览器自动进入网页。
- 学习通插件 0.2.7 单独本地交付：修复监听触发、待核对状态恢复、确认未签到后重新选点和重试，以及航站楼名称匹配；保留 120 秒在途保护，避免重复提交。
