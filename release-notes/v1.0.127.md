# App 1.0.127

## notes

- 新增「设置 → 课表自动化 → 上课自动静音」，默认关闭。按当前账号本学期课表，在上课时静音来电和通知，下课后恢复原来的铃声、振动或静音模式。
- 自动静音支持单双周、自定义课程和调停课；重叠课程结束后再恢复。课中手动调整声音或勿扰模式时保留手动设置，媒体和闹钟音量保持原值。
- 完善声音恢复记录、系统闹钟、重启与后台恢复；关闭功能、退出账号或删除课程时恢复声音。开启时提示勿扰控制及系统所需的闹钟权限，系统强行停止应用后需重新打开以恢复调度。
- 修复脚本浏览器无法加载章节题页 srcdoc 子框架、通过 iframe 读取页面函数失败的问题；保留原脚本及既有跨源访问规则。修复插件长日志无法滚动的问题。
- 同步 SDK 3.7.2 / API 3、网站开发包和公开审核工具链。学习通插件仍为独立本地交付，不随 App 发布或上架。

## verification

自动静音及相关后台恢复、设置回归共 66 项通过，包含 API 24、32、35 的管理器验证。MuMu Android 15 两项设备测试通过：系统准确闹钟在 20:39 自动静音、20:41 自动恢复；验证正常铃声和振动恢复、保留课中手动调整、保留原有静音，媒体与闹钟音量保持原值。使用独立测试包与合成课表，测试后恢复设备声音并移除临时安装包。

浏览器修复包含 v1.0.126 之后已合入的变更；具体设备证据与保存、提交边界见 `spec/CHAOXING-CHAPTER-SRCDOC.md`。此次自动静音验收不代表各厂商后台限制或真实学校课程均已验证。
