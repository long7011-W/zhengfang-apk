# v1.0.91

## notes

修复原生插件打开就提示“调用已取消”的问题，恢复页面、按钮、后台任务和命令调用。
同校插件可经授权共用教务登录响应中的 X-Token，覆盖新旧正方、新旧强智、金智、乘方和正方兼容入口；升级后请重新登录一次。
完善教务选课能力判断、手动队列顺序、成绩学期切换和登录失效恢复，专用单点登录按学校入口使用。
扩大临时教务缓存并调整登录处理时限，减少大课表和登录解析中的容量、超时问题。
修复壁纸下玻璃控件的可读性、导航切换显示及课表日期对齐。
SDK 更新至 3.2.2，开发网站、独立下载包、同校令牌共享文档和示例同步更新。

## changelog

### 原生插件与同校登录共享

- 修复 [#39](https://github.com/znjhahaha/zhengfang-apk/issues/39)：`PluginSandboxClient` 只释放传输资源，操作由创建它的调用方在结果校验后关闭；安装检查补齐操作和会话清理，保留真实取消及过期校验。
- 新增经沙箱客户端返回的生命周期回归，以及最小原生页面 `ui.init` / `ui.reduce` 回归，覆盖此前必然出现的 `CANCELLED`。
- 新增 `academic.session.request@2` 和 `academicSessionToken` 声明。宿主仅从声明的登录接口提取令牌，在认证结果通过 Schema 校验并确认登录成功后存入内存，为获授权的插件注入 `X-Token`。
- 七个入口 `zf`、`zf_old`、`qz`、`qz_old`、`jinzhi`、`chengfang`、`legacy_zf` 均支持声明与继承；`legacy_zf` 共用新正方协议。Cookie 协议继续复用 Cookie，不虚构学校令牌字段。湖北汽车工业学院金智适配更新至 1.1.2。
- 令牌受当前学校、账号、会话代次、认证适配版本和授权范围约束；每次重定向重新检查，撤销、切换及过期后停止使用。普通网络调用不会自动取得教务令牌，版本 1 共享请求保持原有行为。

### 教务流程与界面

- 合入 `codex/grab-ui-regressions`：按真实提交能力显示选课入口；修复手动队列顺序、提交轮次和工作流处理。
- 成绩页面使用适配器支持的学期来源，完善切换、空状态和失败处理；专用 SSO 登录按学校路由，恢复登录失效后的会话更新。
- 临时协议会话缓存扩至 8 MiB，持久存储及 UI 状态仍限制为 256 KiB；认证脚本处理时限为 15 秒，查询时限仍为 5 秒，并修正沙箱中断的错误映射。
- 修复壁纸背景下玻璃表面和文字的可读性、导航与模式切换显示、选择控件及课表头部日期对齐；补充相关回归与设备测试源码。

### SDK、网站与分支核对

- SDK 3.2.2 保持 API 主版本 3，同步契约源、生成资产、类型、CLI 校验、七个继承入口和共享登录文档；新增独立 SDK 编译消费示例。
- 合入插件仓库 `codex/ujn-sso` 的济南大学 SSO 适配及临时协议缓存调整，开发套件和网页下载包重新构建。此项不代表学校插件已在正式目录发布。
- 更新 SDK 网页、Agent 提示词、独立 SDK 下载和同校令牌共享指南。此次新增共享能力需要 App 1.0.91，升级后重新登录以取得令牌。
- 以最后实际发布的 `v1.0.90`（`6a559e7`）为基线，涵盖 App 的 `192b69a`、`69c59e0` 及本次修复，插件仓库的 `e6bf4f9`、`14e350e` 及网站更新。已核对所有远端分支和原工作区本地分支；仅宣传片计划分支不属于本次 App 发布范围。
- 本地验证包括 App JVM 回归、设备测试源码编译、lint，SDK/插件与网站回归，以及独立 SDK 解压重建。此次未执行真实学校账号或设备验收，不能将合成样本通过视为所有学校实测通过。
