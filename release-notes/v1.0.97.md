# 1.0.97

## notes

- 已记住的校园服务共享登录会在重启 App 后自动恢复，无需重复点击使用教务登录；登录确实失效时保留授权并提示重新登录。
- 共享学校登录按准确站点一次授权，减少读取正文、更新已读及刷新时的重复确认；旧插件继续兼容。
- 修复部分机型插件进程启动配置回归，完善启动阶段诊断与失效连接回收；课表刷新或节次补充失败时保留已有数据。
- 新正方成绩使用当前学年及前七学年的内置常用学期，并合并学校返回列表；随日期补充到来的学期，默认隐藏未来学年，保留实际有成绩的学期。
- 修复共用下拉列表后排文字长期半透明或消失，支持两行学期名称和大字体。
- 成绩下拉栏恢复原内容区宽度，修复收起时左边缩进；修复关闭液态玻璃时课表与成绩顶栏的遮罩显示。
- 恢复新正方网页筛选、多选、应用和清空；选课未开放时明确提示并禁用筛选。应用后重新向学校查询。
- 设置首页恢复“退出预览 / 退出登录”；预览退出保留真实账号和缓存。
- 统一教务适配卸载与内置插件停用入口，精简插件分类、详情和账号设置；补充基础大屏布局。
- 课程详情支持插件返回的课程号、学分、教学班、授课内容和备注等字段；课表节数随有效作息同步，手动设置优先。
- SDK 3.2.7 / API 3，新能力最低 App code 97；旧插件继续兼容。

## changelog

本次包含1.0.96开发分支尚未正式发布的修复，以及1.0.97测试期间的后续调整。两个仓库现存本地与远端分支均经提交祖先关系核对，其他分支已包含在修复分支，可将 main 快进整合。

已记住的同意记录与运行时登录会话分开恢复，旧共享句柄失效，撤销及账号切换后重新检查；不会自动重放已经交付执行的插件操作。首次授权和高风险业务入口仍保留必要确认。

为兼容报告中的插件启动失败，插件服务使用非导出的独立进程，与主 App 同 UID；不再具有隔离 UID 对引擎逃逸的额外保护。宿主凭证隔离、来源检查及资源限制继续执行，不能声称安全隔离完全相同。

成绩收起与展开使用相同的原内容区左右边界，不额外加宽菜单；常规字体收起高度仍为50dp，菜单允许两行。内置学期只对声明支持标准学期编号的提供者生效，不改变课表真实当前学期。

本地宽度回归12项通过，恢复共享登录回归62项通过；正式CI的完整JVM、lint与签名安装包验证结果记录于交付报告。学校开放后的实际筛选、用户设备GPU绘制、Android17及反馈学校在线数据仍待确认，不将模拟测试描述为真实学校验收。
