# App 1.0.125

## notes

- 修复辽宁工程技术大学在 App 输入账号密码后，仍需在统一认证网页重复填写的问题。现在会自动带入本次输入并调用学校登录流程，保留学校的密码加密和滑块验证。
- 学校验证完成后自动进入教务主页，核对身份与真实会话，再返回 App 保存登录状态；尚未进入教务时点击“完成登录”会提示继续验证。
- 完善辽宁工大登录页动态加载、重复提交和手动修改输入的处理。自动填写严格限定学校 WebVPN 地址、认证路径、CAS 服务和表单目标，临时凭据不写入网址或页面恢复状态。
- 包含 v1.0.124 打包后的两项维护更新：SDK 3.7.0 审核自检要求覆盖青果与辽宁工大用例；修复 ARM 安装包清单尚未传播完成时，镜像交付提前失败的问题。
- SDK 3.7.0 / API 3 保持兼容，辽宁工大学校插件继续使用已上架的 1.0.0 版本。

## verification

本地相关 JVM 测试 10 项、Android WebView 合成页面测试 7 项和 MuMu 真实学校登录测试 1 项全部通过。Debug、独立 uiPreview 及其 AndroidTest 安装包构建通过。

真实登录从独立测试包的生产 LoginActivity 密码入口发起，完成账号密码自动填写、学校滑块验证、进入教务、自动返回、真实身份匹配、会话校验、账号绑定、登录状态保存及 RESULT_OK 检查。没有使用预览主页面的演示课表作为成功依据。设备为 MuMu Android 12；该记录不代表所有手机兼容。

真实账号、密码、Cookie、原始个人响应和测试私有输入不进入源码、发布包或公开审核。选退课等学校业务写入不在本次验证范围内。
