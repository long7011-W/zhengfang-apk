# 1.0.118 课表、自习与桌面小组件更新

## notes

- 补齐 1.0.117 发布后经 PR #63 合入 main 的课表改进，包含 PR #62 的有效改动。
- 课表支持按账号设置每周起始日，周次计算、课表列顺序、提醒和日历导出保持一致；日视图顶部日期条支持整周滑动。
- 新增早、晚自习时间段，按账号和学期保存，支持独立提醒；完善自习与课程的重复判断、跨夜冲突和删除撤销后的课程快照恢复。
- 新增桌面倒计时小组件，显示距离课程上课或下课的实时倒计时；补齐各类小组件预览，并修复部分桌面无法列出小组件的问题。
- 课程详情和课程卡片显示实际生效的提醒提前量，兼容全局设置与单门课程覆盖。
- 补齐历史更新记录、文档索引和旧文档归档；新增提交与 PR 的 JVM 自动检查，统一测试时区。
- 延续 1.0.117 的插件页面间距修复。SDK 3.6.0 / API 3 保持兼容，本次为普通更新。

## validation

执行发布脚本回归、JVM 单元测试、Android 测试源码编译、Lint 与签名安装包构建，并同步网站开发包、Wiki 和公开审核工具链。实际结果以本次 CI 和交付收据为准。本轮按用户要求不运行实机或模拟器测试。
