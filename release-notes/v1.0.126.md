# App 1.0.126

## notes

- 修复河北传媒学院统一身份认证成功后，经过 `/ticketlogin`、`/xtgl/` 仍被宿主拦截的问题。精确教务回调响应后，可继续访问已授权的同源读取页面，并沿用教务 Cookie；继续兼容原作者 1.1.3 学校插件。
- 青果通用协议增加已配置 CAS AES 登录的账号密码接入，解决选择通用协议后仍无条件进入 Cookie 网页登录的问题。使用学校实时表单和加密参数；其他认证形式保留网页登录，不猜测加密方式。
- 完善教务新会话保存与复用验证，保留用户选择的学校扩展。青果课表解析及缓存逻辑没有调整。
- 同步 SDK 3.7.1 / API 3、CLI 和审核工具的认证跳转规则，逐跳检查来源、路径、方法和回调阶段，保留票据、跨域、HTTPS、跳数及写入禁止重放保护。
- 支持插件将网络用途细分为最多 80 条规则，超过原有 60 条的插件需声明 App 126。学习通本地插件 0.2.10 据此将章节题页读取与进度写入分开，修复正常 302 读取被误停为“结果待核对”的问题；该插件仅本地交付，不随 App 上架。

## verification

受影响的 App 单元测试 8 项通过，uiPreview App 和 AndroidTest 构建通过。MuMu Android 15 实测青果学校扩展及通用协议均完成生产登录入口的密码登录、新 Cookie 保存、重建适配器后会话复用，课表首次和刷新均为 18 条；河北传媒使用原作者 1.1.3 插件完成验证码登录和会话复用，课表首次与刷新均为 14 条。

学习通最终本地包经生产 PluginHost 读取真实无 jobid 章节题页成功，题目 DOM 存在、purpose 为 query、未发送 mutation；独立作业列表读取成功。没有运行九九脚本、第三方题库或完整刷课队列，没有保存或提交答案。真实独立作业题页作答、真实学校选退课和其他设备不在本轮验收范围。

平台全套 344 项、网站 206 项、浏览器 24 项通过；补齐 CLI 旧样本写入未知保护后，受影响的认证、协议和权限回归 51 项通过。学习通本地独立回归 211 项、最终 check/test/submit-check 及请求用途回归通过。SDK/Starter 已独立解压验证，宿主资源、内置协议、网站 build/typecheck 与部署 dry-run 通过。

账号、密码、Cookie、ticket、enc 和真实题目正文不进入源码、安装包或公开审核样本。
