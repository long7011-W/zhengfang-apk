# v1.0.95

## notes

修复部分学校成绩页学期列表为空或缺少历史学期的问题，合并读取课表与成绩查询页提供的学期选项。
成绩学期选择器增加加载、失败提示和刷新入口，列表为空时也能重试，刷新期间已有学期仍可选择。
包含上一版设置、抢课等页面顶栏文字消失的修复，保留原有实时玻璃效果。

## changelog

### 成绩学期

- 新旧正方、新旧强智公共协议分别读取课表和成绩查询页的学期控件并合并去重，避免课表只开放当前学期时丢失成绩历史选项；强智支持同一教务应用内的成绩查询框架。
- 一处查询页未开放、暂时不可用或结构变化时保留另一处已获取的选项。登录失效、取消和安全策略错误仍中止；两处均无法识别时明确报错，不再制造当前日期对应的可选学期。
- 成绩选择器增加学期列表专用加载与错误提示和刷新操作；空列表可重试，刷新保留已有选项与学期成绩缓存，并继续按插件原始学期 ID 查询。
- 重建压缩后的乘方包继续保留“选课提交尚未支持”的限制，同时保留旧包限制；没有开放新的提交能力。
- 公共协议与学校模板升级至 3.2.2；SDK 保持 3.2.4、API 保持 3。旧锁定协议保留，金智/乘方使用原有实现；第三方插件可升级公共库获得相同修复。

### 验证

- 本地 App 定向回归 15/15，重建内置包后的宿主能力与选择器回归 17/17，完整 JavaScript/QuickJS 回归 198/198；包含 11 项学期来源与失败处理用例、3 项选择器交互用例，以及顶栏文字回归。
- 协议样本为合成学校页面；未执行真实学校写入或设备/模拟器测试。具体学校没有提供的学期不会自行生成，实际学校与 API 32 设备验收仍待完成。
